# Regras do Projeto — Maria Amélia Saúde e Estética

## Fluxo obrigatório após alterações

Sempre que finalizar qualquer alteração em arquivos deste projeto, executar obrigatoriamente:

1. `git add` nos arquivos modificados
2. `git commit` com mensagem descritiva
3. `git push` para o repositório remoto

Não perguntar, não esperar confirmação — fazer automaticamente ao final de cada sessão de edição.
